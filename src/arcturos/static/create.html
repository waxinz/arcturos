Create & Run

Append-only store: creating adds rows; nothing is ever overwritten. Bench sweeps run as async jobs — the progress bar polls until the run is stored; eval replays stay synchronous.

Benchmark run — kick off

Runs a cold-cache sweep. Transport native targets a llama.cpp server (/completion); openai targets any OpenAI-compatible chat server (tabbyAPI, vLLM, litellm — needs a model name). Stores a run + one benchmark row per context target.

Eval suite — create

Creates the suite record; populate results afterwards by replaying it ("Eval replay — kick off").

Eval suite items — define (optional, pre-store)

Suite JSON kept in the browser for dispatch: {"items":[{"id":"x","prompt":"…"}]} or multi-turn {"type":"multi-turn","id":"x","turns":[…]}.

Eval replay — kick off

Replays the JSON from "Eval suite items — definition" against an OpenAI-compatible chat endpoint, stores eval_results.
