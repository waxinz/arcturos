Run evals

Replay an eval suite against a target model as an async job — live per-item progress, stop any time; completed items are kept.

Every item in the suite is sent to the target as a chat request (multi-turn items replay turn by turn) and the answers are stored for judging. Replay requests default to max_tokens 1024 / temperature 0 — reasoning models need headroom to think before answering.
